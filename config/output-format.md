# فرمت خروجی تأییدشده

هر پیشنهاد **همیشه** دو بلوک جدا دارد — همین سبکی که کاربر تأیید کرد.

---

## بلوک ۱ — متن پیشنهاد (چت پونیشا)

- عنوان: **متن پیشنهاد:**
- کوتاه، صمیمی، فنی، اول شخص
- **بدون** عدد زمان، **بدون** عدد قیمت
- جمله ارجاع به فرم: «مبلغ و زمان تحویل رو در بخش پیشنهاد ثبت کردم»
- در پایان درخواست کوچک (لینک، دسترسی، لیست تغییرات) اگر لازم است

## بلوک ۲ — فرم پونیشا

- عنوان: **فرم پونیشا:**
- **هر فیلد جدا** — برچسب یک خط، **فقط مقدار** خط بعد (برای کپی مستقیم در فرم)
- مبلغ‌ها **بدون ویرگول و بدون «تومان»** — فقط عدد
- زمان **بدون «روز»** — فقط عدد
- عنوان و مبلغ هر مرحله **هر کدام خط جدا** — نه `عنوان — مبلغ` در یک خط
- معمولاً ۳ مرحله؛ جمع مبالغ = مبلغ کل
- بین هر فیلد یک خط خالی

### قالب (کپی‌پذیر)

```
زمان تحویل
12

مبلغ کل
11000000

مرحله ۱ — عنوان
تکمیل صفحه اصلی + هدر و فوتر

مرحله ۱ — مبلغ
3300000

مرحله ۲ — عنوان
صفحه فروشگاه و محصول + ووکامرس

مرحله ۲ — مبلغ
4400000

مرحله ۳ — عنوان
تسویه حساب + موبایل + تست

مرحله ۳ — مبلغ
3300000
```

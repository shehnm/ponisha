# رقابت — فریلنسرهای هر پروژه

## قاعده

قبل از نوشتن پیشنهاد، **وضعیت رقبا** را از اسکرین‌شات یا توضیح کاربر بخوان:

- تعداد کسانی که پیشنهاد داده‌اند
- زمان تحویل پیشنهادی آن‌ها (مثلاً ۲ روز، ۵ روز، ۱۵ روز)
- در صورت مشخص بودن: امتیاز یا سطح رقبا

اگر اسکرین نبود، از کاربر نپرس مگر پروژه خیلی مهم باشد — با بازه بودجه و `pricing-guide.md` پیش برو.

---

## چطور روی فرم پونیشا اثر بگذارد

**زمان تحویل (بلوک ۲):**
- اگر بیشتر رقبا ۳–۵ روز زدند -> زمان ما نزدیک همان بازه (نه ۱۵ روز) مگر scope سنگین باشد
- اگر رقبا ۱۵–۴۰ روز -> می‌توان کمی بالاتر رفت برای پروژه بزرگ
- همیشه واقع‌بینانه — وعده ۲ روز برای پروژه ۲۰ روزه ممنوع

**مبلغ (بلوک ۲):**
- **اول:** بازه بودجه صفحه پروژه را بخوان — مبلغ **حتماً داخل همان رنج** (نه زیر کف)
- رقابت زیاد (۱۰+ پیشنهاد) -> میانه–پایین **بازه** کارفرما، نه کف (بی‌تجربه) و نه بیرون بازه
- رقابت کم (۱–۳ پیشنهاد) -> میانه–بالای بازه مجاز
- بودجه بالا (۱۰۰M+) -> کیفیت و مراحل مهم‌تر از ارزان بودن

**متن پیشنهاد (بلوک ۱):**
- تعداد رقبا را **ننویس**
- تمایز را با روش فنی بنویس (ابزار اختصاصی، تجربه ووکامرس، مرحله‌ای بودن)

- سطح ۰ -> قیمت رقابتی‌تر، متن فنی‌تر
- امتیاز ۴.۹ -> می‌توان به کیفیت و پاسخ سریع اشاره کرد (یک جمله، نه تبلیغ)

# فرمت خروجی تأییدشده

هر پیشنهاد **همیشه** دو بلوک جدا دارد — همین سبکی که کاربر تأیید کرد.

---

## بلوک ۱ — متن پیشنهاد (چت پونیشا)

- **عنوان دقیق:** `**متن پیشنهاد:**` — همین خط اول بلوک (قابل کپی)
- **بدون** `###`، **بدون** جدول markdown، **بدون** code fence (```) دور متن
- متن ساده و پیوسته — کاربر باید بتواند کل بلوک را یک‌جا کپی کند
- کوتاه، صمیمی، فنی، اول شخص
- **بدون** عدد زمان، **بدون** عدد قیمت
- جمله ارجاع به فرم: «مبلغ و زمان تحویل رو در بخش پیشنهاد ثبت کردم»
- در پایان درخواست کوچک (لینک، دسترسی، لیست تغییرات) اگر لازم است

## بلوک ۲ — فرم پونیشا

- **عنوان دقیق:** `**فرم پونیشا:**` — بعد از `---` جداکننده
- **بدون** code fence — هر خط plain text برای paste در فیلدهای پونیشا
- زمان تحویل: X روز (فقط اینجا)
- مبلغ کل: X تومان (فقط اینجا)
- مرحله ۱ — عنوان — مبلغ
- مرحله ۲ — ...
- معمولاً ۳ مرحله؛ جمع = مبلغ کل

---

## نمونه کامل (تأییدشده)

`examples/woocommerce-sections.txt`

## ممنوع

- قاطی کردن قیمت/زمان داخل متن پیشنهاد
- فقط یک بلوک دادن بدون فرم پونیشا
- جدول markdown در متن پیشنهاد
- **code fence (```) دور متن پیشنهاد یا فرم** — مانع کپی راحت
- عنوان `### بلوک ۱` به‌جای `**متن پیشنهاد:**` / `**فرم پونیشا:**`

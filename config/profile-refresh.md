# به‌روزرسانی پروفایل — قانون استاندارد

## بازه زمانی

**هر ۷ روز یک‌بار** (حداکثر) پروفایل از پونیشا خوانده و `config/profile.md` آپدیت می‌شود.

| مورد | مقدار |
|------|--------|
| بازه refresh | ۷ روز |
| منبع | https://ponisha.ir/profile/shehneh |
| فایل مقصد | `config/profile.md` |

---

## کی sync کنیم

### ۱. قبل از هر پیشنهاد / جستجوی روزانه پونیشا (اجباری)

1. پروفایل را از https://ponisha.ir/profile/shehneh بخوان (حداقل **روزی یک‌بار** قبل از جستجوی پروژه)
2. **مهارت‌های ثبت‌شده** را با `config/profile.md` مقایسه کن — اگر عوض شده، فایل را آپدیت کن
3. جستجوی پروژه فقط بر اساس **مهارت‌های فعلی پروفایل** (نه حدس قبلی)
4. اگر **بیش از ۷ روز** از آخرین sync گذشته -> sync کامل + تاریخ‌ها را عوض کن
5. اگر کمتر از ۷ روز ولی مهارت عوض نشده -> همان فایل محلی کافی است

### ۲. فوری (بدون انتظار ۷ روز)

- کاربر گفت پروفایل عوض شد
- پروژه تمام شد / نظر جدید / سطح عوض شد
- نمونه‌کار یا «درباره من» عوض شد

### ۳. بعد از sync موفق

در `profile.md` به‌روز کن:
- آخرین sync = تاریخ امروز
- sync بعدی = امروز + ۷ روز

---

## چه فیلدهایی sync شوند

- امتیاز، تعداد نظر، سطح
- پروژه انجام‌شده / در حال انجام
- امتیاز کل، پاسخ‌گویی
- متن «درباره من»
- مهارت‌ها
- سوابق کاری (خلاصه)

---

## commit

بعد از sync پروفایل، اگر تغییر بود -> commit به ریپو با پیام مثل: `sync پروفایل shehneh`

فقط وقتی کاربر پیشنهاد می‌دهد یا خودش گفت پروفایل عوض شد — هر sync خودکار commit لازم نیست مگر تغییر معنادار باشد.

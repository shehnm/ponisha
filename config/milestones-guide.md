# راهنمای مراحل + قیمت

## قواعد

- جمع مبالغ = مبلغ کل پیشنهاد
- عنوان هر مرحله برای فیلد پرداخت امن پونیشا قابل کپی باشد
- روز کاری در پرانتز (اختیاری در فرم، مفید در چت)
- اگر کارفرما «پرداخت امن» گفت، نسخه ۳مرحله‌ای هم بده

## الگوی ۴ مرحله (پروژه بزرگ)

| # | عنوان | درصد تقریبی |
|---|--------|-------------|
| ۱ | جمع‌بندی / wireframe / بررسی | ۱۵–۲۰٪ |
| ۲ | طراحی UI | ۲۵–۳۰٪ |
| ۳ | پیاده‌سازی / شخصی‌سازی اصلی | ۴۰–۴۵٪ |
| ۴ | تست و تحویل | ۱۰–۱۵٪ |

## الگوی ۳ مرحله (پرداخت امن ساده)

| # | عنوان | درصد |
|---|--------|------|
| ۱ | شروع + فاز اول | ۳۰٪ |
| ۲ | فاز میانی (طراحی یا توسعه) | ۴۰٪ |
| ۳ | تکمیل + تحویل | ۳۰٪ |

## فرمت خروجی در چت

```
مرحله ۱ — [عنوان] — [مبلغ] تومان ([روز] روز)
...
جمع: [کل] تومان — [کل روز] روز کاری
```

بدون جدول markdown در متن پیشنهادی که به کارفرما می‌فرستم — فقط وقتی خودم مراحل را جداگانه می‌خواهم (مثل الان).

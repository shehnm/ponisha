# Inbox — Life OS

**ورودی مرکزی** اطلاعات جدید قبل از طبقه‌بندی و انتقال به حوزه مناسب.

---

## منابع مجاز

- ChatGPT
- Cursor Ponisha
- Cursor Odoo
- Cursor Book
- Cursorهای آینده
- گزارش شخصی نویسنده

---

## جریان کار

```
ورودی جدید → inbox/updates.md
           → تعیین حوزه Life OS
           → طبقه‌بندی (FACT/DECISION/…)
           → به‌روز Living Documents
           → وضعیت نهایی در updates.md
```

---

## وضعیت‌های Inbox

| وضعیت | معنی |
|--------|------|
| **ثبت شد** | پردازش و منتقل به Living Doc |
| **نیاز به تصمیم** | منتظر تصمیم نویسنده |
| **نیاز به اطلاعات بیشتر** | Data gap |
| **تبدیل به پروژه** | → `projects/` |
| **تبدیل به مسئولیت** | → `responsibilities/` |
| **تبدیل به درس** | → `lessons/` |
| **تبدیل به تصمیم** | → `decisions/` |
| **آرشیو / بدون اقدام** | بدون تغییر Life OS |

---

## قانون

> Inbox **قبرستان اطلاعات نیست**.  
> هر مورد باید به یکی از وضعیت‌های بالا برسد.

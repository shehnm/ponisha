## Lessons فعال (از انسان + نتیجه)

### [Human] — قوانین عملیاتی (از بازخورد کاربر)

- **[Human] #1 — ترتیب شروع:** دغدغه کارفرما → پیامد اشتباه → راه‌حل → جزئیات فنی. نه ورود مستقیم به ووکامرس/ساختار فنی.
- **[Human] #2 — اعتماد بدون رزومه:** یک جمله تجربه مرتبط **واقعی** از `profile.md` (مثلاً وردپرس/ووکامرس — دوباره‌کاری از ساختار محصول). **اختراع ممنوع.**
- **[Human] #3 — لحن:** «می‌زنم» زیاد محاوره‌ای است → «اجرای پروژه را با وردپرس و ووکامرس انجام می‌دهم» — حرفه‌ای ولی صمیمی.
- **[Human] #4 — ریسک:** قبل از import/ریسک فنی، **دلیل اهمیت** برای کارفرما (مثلاً «اگر محصول زیاد باشد، ساختار ورود اطلاعات از اول مشخص شود»).
- **[Human] #5 — سؤال پایانی:** → منتقل به `[Human][Keep]` زیر

### [Human][Keep] — همیشه حفظ کن

- **[Human][Keep]** #749144: سؤال تخصصی پایانی که تحلیل پروژه را نشان می‌دهد — **حفظ شود.**

### [Human] — اصلاح (ادامه)

- **[Human] #6 — چک قبل از جمله اول:** «اولین جمله برای کارفرما چه احساسی ایجاد می‌کند؟» اگر فقط فنی است → بازنویسی. هدف: «مشکل من را فهمیده.»

## تحلیل پس از نتیجه (اجباری)

وقتی نتیجه مشخص شد، agent این سؤالات را جواب دهد و در **تحلیل نهایی** بنویسد:

### اگر بردیم

1. کدام بخش Proposal احتمالاً تأثیرگذار بود؟ (ریسک؟ insight؟ سؤال پایانی؟)
2. قیمت/زمان نسبت به رقبا چطور بود؟
3. چه الگویی را در پیشنهادهای بعدی **تکرار** کنیم؟

### اگر باختیم یا بی‌پاسخ

1. مشکل احتمالی از کجا بود؟ (یک یا چند مورد)
   - شروع Proposal
   - اعتمادسازی
   - قیمت (زیر/بالای بازه؟ خیلی بالا/پایین؟)
   - زمان (خیلی کوتاه/بلند؟)
   - سؤال پایانی (ضعیف یا نبود؟)
   - تحلیل پروژه (سطحی بود؟)
   - ریسک (عمومی بود نه خاص پروژه؟)
   - insight (مصنوعی یا نبود؟)
   - رقابت (تعداد زیاد؟)
2. آیا کارفرما فریلنسر دیگری انتخاب کرد؟ (اگر معلوم است)
3. **Lesson Learned** — یک جمله actionable برای سیستم

## استفاده در تولید Proposal بعدی

**قبل از نوشتن بلوک ۱،** agent باید:

1. این فایل را برای **همان دسته‌بندی** پروژه بخواند
2. Lessonهای `[Human]` و `[Human][Keep]` و **Best Practices** مرتبط را در نظر بگیرد
3. جدول **بازخورد تکرارشونده** را چک کند
4. الگوهای **برنده** را ترجیح دهد؛ الگوهای **بازنده** و **Human** را اجتناب کند

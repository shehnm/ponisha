## بلوک ۲ — فرم پونیشا

- عنوان: **فرم پونیشا:**
- مبلغ کل **داخل بازه بودجه پروژه** (طبق `pricing-guide.md`)
- معمولاً ۳ مرحله؛ جمع مبالغ مراحل = مبلغ کل

### قانون نمایش (کپی آسان)

**هر فیلد جدا** — مطابق فیلدهای واقعی فرم پونیشا.

- **نه** یک code block ترکیبی برای همه فیلدها
- **نه** یک پاراگراف با خطوط پشت‌سرهم
- هر فیلد: برچسب `📋` + **یک** code block جدا
- داخل هر code block **فقط** مقداری که در همان فیلد پونیشا paste می‌شود

### فیلدها (به ترتیب)

1. زمان تحویل — فقط عدد روز (بدون «روز»)
2. مبلغ کل — فقط عدد با جداکننده هزارگان (بدون «تومان»)
3. عنوان مرحله ۱ — فقط عنوان (بدون «مرحله ۱ —»)
4. مبلغ مرحله ۱ — فقط عدد
5. عنوان مرحله ۲ — فقط عنوان
6. مبلغ مرحله ۲ — فقط عدد
7. عنوان مرحله ۳ — فقط عنوان
8. مبلغ مرحله ۳ — فقط عدد

(اگر ۴ مرحله بود، همین الگو ادامه پیدا کند.)

### قالب هر فیلد

```markdown
📋 [نام فیلد]

\`\`\`text
[مقدار paste]
\`\`\`
```

### ممنوع در بلوک ۲

- ترکیب عنوان + مبلغ در یک code block (مثلاً `عنوان — ۱,۹۵۰,۰۰۰ تومان`)
- پیشوند «مرحله ۱ —» داخل مقدار paste
- کلمه «تومان» یا «روز» داخل code block
- جدول markdown برای فرم
- یک code block چندخطی شامل همه فیلدها

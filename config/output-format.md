# فرمت خروجی تأییدشده — Copy-Friendly

هر پیشنهاد **همیشه** دو بلوک جدا دارد.

**موتور بلوک ۱:** `proposal-engine.md` + `personal-voice.md`
**یادگیری:** `proposal-learning.md`
**Human Review:** `human-review-loop.md` — بعد از هر پیش‌نویس؛ قبل از نسخه نهایی
**موتور بلوک ۲:** `config/pricing-guide.md` + `config/milestones-guide.md`
**ثبت پیش‌نویس:** `config/last-proposal.md` — شامل **لینک پروژه**

---

## چک نهایی (اجباری)

قبل از تحویل:

1. آیا **لینک پروژه** در مرحله ۰ آمده؟ `https://ponisha.ir/project/{ID}`
2. آیا هر code block با یک کلیک Copy → Paste در پونیشا می‌شود؟
3. آیا «**پونیشا**» درست نوشته شده؟ (نه Ponisha)

**خیر** → بازنویسی. **بله** → تحویل + به‌روز `last-proposal.md`

---

## نام‌گذاری پونیشا (Naming — اجباری)

1. نام پلتفرم **فقط:** **پونیشا** (پ + و + ن + ی + ش + **ا** فارسی)
2. **ممنوع در متن فارسی:**
   - `Ponisha` / `Punisha`
   - «پونیش» + حرف لاتین `a` — اشتباه رایج agent ❌
   - «بعد» + حرف لاتین `i` — اشتباه رایج agent ❌
   - هر FA+EN قاطی داخل یک کلمه فارسی
3. **مجاز جدا از متن:** URL (`ponisha.ir`)، مسیر ریپو (`shehnm/ponisha`) — در خط جدا
4. **چک قبل از تحویل:** در کل خروجی (مرحله ۰، پیشنهاد، گزارش) فقط «پونیشا» — نه حرف لاتین داخل کلمه

---

## مرحله ۰ — ارزیابی (اجباری — برای کاربر)

**قبل از بلوک ۱ و ۲** — همیشه این سه خط:

```
### مرحله ۰ — ارزیابی (#{ID})

**{عنوان پروژه}**

لینک: https://ponisha.ir/project/{ID}
```

سپس بلوک ارزیابی (قابل انجام؟ ریسک؟ Fit؟ رقابت؟ بودجه؟ Freshness؟).

**ممنوع:** مرحله ۰ بدون ID یا **بدون لینک** — حتی اگر پیشنهاد عالی باشد.

همین لینک باید در `config/last-proposal.md` → فیلد «لینک پروژه» ثبت شود.

---

## قانون کپی آسان (هر دو بلوک)

خروجی برای **کپی یک‌کلیکی** است — نه خواندن در چت.

- بلوک ۱: یک code block = کل متن چت پونیشا
- بلوک ۲: هر فیلد فرم = یک code block جدا
- داخل code block **فقط** مقدار paste — بدون عنوان بلوک، بدون توضیح agent

---

## بلوک ۱ — متن پیشنهاد (چت پونیشا)

- عنوان بیرون code block: **متن پیشنهاد:**
- طبق `proposal-engine.md`: تحلیل داخلی + امتیاز ≥۹۰ در ۸ معیار
- ۴–۸ جمله؛ حداکثر ~۱۲ خط
- **بدون** عدد زمان، **بدون** عدد قیمت
- شامل: درک مسئله، رویکرد، یک ریسک/راه‌حل، بینش، ارجاع به فرم، **سؤال تخصصی پایانی**
- صدای توسعه‌دهنده — نه فروشنده، نه template

### قانون نمایش (کپی آسان)

- برچسب `📋 متن پیشنهاد` + **یک** code block
- داخل code block: **فقط** متنی که در چت پیشنهاد پونیشا paste می‌شود
- خط خالی بین پاراگراف‌ها مجاز است (خوانایی بعد از paste)
- **نه** نوشتن متن پیشنهاد به‌صورت پاراگراف معمولی markdown بدون code block
- **نه** قرار دادن «متن پیشنهاد:» یا عنوان دیگر داخل code block

### قالب

```markdown
**متن پیشنهاد:**

📋 متن پیشنهاد

\`\`\`text
[کل متن چت — از سلام تا سؤال پایانی]
\`\`\`
```

### ممنوع در بلوک ۱

- قیمت یا زمان (عدد) داخل code block
- جدول markdown
- متن پیشنهاد خارج از code block (به‌جز عنوان بلوک)

### نمونه خروجی (#749390)

**متن پیشنهاد:**

📋 متن پیشنهاد

```text
سلام وقت بخیر.

حدود ۴۰۰ محصول سفال و سرامیک دارید. اول نمونه‌ای از داده‌های فعلی و فیلدهایتان را می‌بینم. از روی همان mapping دسته‌بندی و import مرحله‌ای را می‌چینم.

توضیحات صنایع دستی باید هم خلاق باشد هم یکدست. اگر ساختار از اول درست نباشد، سئو قبلی ضربه می‌خورد.

قبل از انتقال کامل، چند محصول را نمونه منتقل می‌کنم تا اصلاح ساختار یا توضیحات همان ابتدا انجام شود. مبلغ و زمان را در فرم ثبت کردم.

اطلاعات محصولات الان در چه شکلی در دسترس است — فایل اکسل، خروجی سایت قبلی، یا ورود دستی؟
```

**هدف:** یک کلیک Copy → paste مستقیم در چت پیشنهاد پونیشا (بدون انتخاب دستی متن فارسی/انگلیسی).

---

## بلوک ۲ — فرم پونیشا

- عنوان: **فرم پونیشا:**
- مبلغ کل **داخل بازه بودجه پروژه** (طبق `pricing-guide.md`)
- معمولاً ۳ مرحله؛ جمع مبالغ مراحل = مبلغ کل

### قانون نمایش (کپی آسان)

**هر فیلد جدا** — مطابق فیلدهای واقعی فرم پونیشا.

- **نه** یک code block ترکیبی برای همه فیلدها
- **نه** یک پاراگراف با خطوط پشت‌سرهم
- هر فیلد: برچسب `📋` + **یک** code block جدا
- داخل هر code block **فقط** مقداری که در همان فیلد پونیشا paste می‌شود

### فیلدها (به ترتیب)

1. زمان تحویل — فقط عدد روز (بدون «روز»)
2. مبلغ کل — فقط عدد با جداکننده هزارگان (بدون «تومان»)
3. عنوان مرحله ۱ — فقط عنوان (بدون «مرحله ۱ —»)
4. مبلغ مرحله ۱ — فقط عدد
5. عنوان مرحله ۲ — فقط عنوان
6. مبلغ مرحله ۲ — فقط عدد
7. عنوان مرحله ۳ — فقط عنوان
8. مبلغ مرحله ۳ — فقط عدد

(اگر ۴ مرحله بود، همین الگو ادامه پیدا کند.)

### قالب هر فیلد

```markdown
📋 [نام فیلد]

\`\`\`text
[مقدار paste]
\`\`\`
```

### ممنوع در بلوک ۲

- ترکیب عنوان + مبلغ در یک code block (مثلاً `عنوان — ۱,۹۵۰,۰۰۰ تومان`)
- پیشوند «مرحله ۱ —» داخل مقدار paste
- کلمه «تومان» یا «روز» داخل code block
- جدول markdown برای فرم
- یک code block چندخطی شامل همه فیلدها

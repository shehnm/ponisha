# یادگیری از نتایج — Proposal Intelligence

این فایل **حافظه تجربی سیستم** است. هدف: Proposalهای آینده بر اساس نتایج واقعی بهتر شوند — نه حدس.

**ارتباط با فایل‌های دیگر:**
- `bids-log.md` — ثبت سریع bid ارسال‌شده (ID، مبلغ، زمان)
- این فایل — تحلیل عمیق‌تر + یادگیری + الگو استخراج

---

## چه زمانی ثبت شود

| تریگر کاربر | عمل |
|-------------|-----|
| «پیشنهاد دادم» | ردیف در `bids-log.md` + **ردیف اولیه** اینجا (وضعیت: `منتظر نتیجه`) |
| «پاسخ داد» / «کارفرما جواب داد» | آپدیت: `پاسخ کارفرما = بله` |
| «بردیم» / «پروژه رو گرفتم» | آپدیت: `برنده = بله` + تحلیل پس از پیروزی |
| «باختیم» / «انتخاب نشدم» | آپدیت: `برنده = خیر` + تحلیل پس از شکست |
| «رد شد» / «بی‌پاسخ ماند» | آپدیت وضعیت + تحلیل |

**بعد از هر نتیجه نهایی (برد/باخت/بی‌پاسخ):** بخش **تحلیل پس از نتیجه** اجباری است.

## تحلیل پس از نتیجه (اجباری)

وقتی نتیجه مشخص شد، agent این سؤالات را جواب دهد و در **تحلیل نهایی** بنویسد:

### اگر بردیم

1. کدام بخش Proposal احتمالاً تأثیرگذار بود؟ (ریسک؟ insight؟ سؤال پایانی؟)
2. قیمت/زمان نسبت به رقبا چطور بود؟
3. چه الگویی را در پیشنهادهای بعدی **تکرار** کنیم؟

### اگر باختیم یا بی‌پاسخ

1. مشکل احتمالی از کجا بود؟ (یک یا چند مورد)
   - شروع Proposal
   - اعتمادسازی
   - قیمت (زیر/بالای بازه؟ خیلی بالا/پایین؟)
   - زمان (خیلی کوتاه/بلند؟)
   - سؤال پایانی (ضعیف یا نبود؟)
   - تحلیل پروژه (سطحی بود؟)
   - ریسک (عمومی بود نه خاص پروژه؟)
   - insight (مصنوعی یا نبود؟)
   - رقابت (تعداد زیاد؟)
2. آیا کارفرما فریلنسر دیگری انتخاب کرد؟ (اگر معلوم است)
3. **Lesson Learned** — یک جمله actionable برای سیستم

---

## استفاده در تولید Proposal بعدی

**قبل از نوشتن بلوک ۱،** agent باید:

1. این فایل را برای **همان دسته‌بندی** پروژه بخواند
2. Lesson Learnedهای مرتبط را در نظر بگیرد
3. الگوهای **برنده** را ترجیح دهد؛ الگوهای **بازنده** را اجتناب کند

**مثال استخراج الگو:**

| اگر Lesson می‌گوید… | در Proposal بعدی… |
|---------------------|-------------------|
| «شروع با ریسک import جواب گرفت» | برای فروشگاه‌های مشابه، ریسک داده/import را زودتر بیاور |
| «قیمت زیر میانه — بی‌اعتماد» | میانه بازه را رعایت کن |
| «سؤال پایانی کلی — پاسخی نیامد» | سؤال تخصصی‌تر بپرس |
| «insight مصنوعی — رد شد» | insight ننویس |

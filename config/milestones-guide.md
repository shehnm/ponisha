# راهنمای مراحل + قیمت

**فقط برای پر کردن فرم پونیشا** — نه داخل متن پیشنهاد چت.

## قواعد

- جمع مبالغ = مبلغ کل پیشنهاد (فیلد مبلغ کل)
- زمان تحویل کل = فیلد جدا در پونیشا (نه در متن پیشنهاد)
- عنوان هر مرحله برای فیلد پرداخت امن قابل کپی باشد
- اگر کارفرما «پرداخت امن» گفت، نسخه ۳مرحله‌ای هم بده

## الگوی ۴ مرحله (پروژه بزرگ)

| # | عنوان | درصد تقریبی |
|---|--------|-------------|
| ۱ | جمع‌بندی / wireframe / بررسی | ۱۵–۲۰٪ |
| ۲ | طراحی UI | ۲۵–۳۰٪ |
| ۳ | پیاده‌سازی / شخصی‌سازی اصلی | ۴۰–۴۵٪ |

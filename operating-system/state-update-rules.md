# قوانین به‌روزرسانی وضعیت

**نسخه:** 1.0

---

## قانون اصلی

وقتی **اطلاعات مهم جدید** ثبت شد:

1. **فقط** فایل جدید نساز — مگر Snapshot تاریخی باشد.
2. بررسی کن آیا Living Document زیر **واقعاً** نیاز به تغییر دارد:

| فایل | شرط به‌روزرسانی |
|------|-----------------|
| `state/current-state.md` | هر تغییر در وضعیت کلان، Pending، Deadline، ریسک |
| `priorities/current-priorities.md` | تغییر اولویت — **نه** بدون دلیل |
| `management-overview` مرتبط | تغییر در حوزه (مثلاً پونیشا) |
| `projects/` | پروژه جدید / تغییر وضعیت |
| `finance/` | اثر مالی (درآمد، هزینه، تعهد) |
| `responsibilities/` | اثر خانوادگی |
| `decisions/decision-log.md` | تصمیم مهم جدید |
| `lessons/` | درس **قابل تکرار** و تأییدشده |

3. اگر تغییر نبود → Living Document را **دست نزن**.

---

## پس از Handoff

```
Handoff دریافت
  → طبقه‌بندی FACT/DECISION/…
  → به‌روز Living Documents مرتبط
  → inbox: وضعیت «ثبت شد»
  → Snapshot فقط اگر گزارش دوره‌ای درخواست شد
```
